# CestaSmart 2.10 — producto genérico sin variantes no solicitadas

Regla general:
Cuando el usuario escribe un producto genérico, CestaSmart busca la versión estándar más económica
con la misma calidad. No introduce variantes especiales salvo que estén expresamente solicitadas.

Ejemplos:
- CAFÉ -> no cápsulas, no soluble, no sabores, no descafeinado salvo petición.
- SALSA DE TOMATE -> no arrabbiata, albahaca, pesto, picante, etc. salvo petición.
- JAMÓN COCIDO -> no pavo/pollo, no serrano/ibérico.
- YOGUR NATURAL -> no sabores añadidos salvo petición.
- LECHE -> no sabores añadidos salvo petición.
- GEL DE BAÑO -> no variantes medicinales/específicas salvo petición.

Objetivo:
primero el producto estándar más barato con la misma calidad.
