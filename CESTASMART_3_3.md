# CestaSmart 3.3

- Detergente genérico: estándar líquido.
- No mezcla líquido, polvo, cápsulas/pastillas o lavado a mano salvo petición expresa.
- Variantes como prendas delicadas no entran salvo que se soliciten.
- Eroski: el precio principal debe ser el precio del envase completo.
- €/lavado, €/rollo, €/kg y €/l quedan como precios normalizados secundarios.
- Familia queda fuera del ranking mientras el conector no devuelva precios fiables.
